# Changelog

- Added five complete 198-task Hugging Face administrations: GLM-4.5V, Gemma 3
  4B, Gemma 3 12B, Qwen3-VL 30B, and Qwen2.5-VL 72B.

  retries, provider-specific routing, and per-task progress.
- Added the grayscale preprint, appended online supplement, result tables, and
  reproducible figure-generation scripts.
- Expanded the test suite for Hugging Face and OpenAI provider adapters.
